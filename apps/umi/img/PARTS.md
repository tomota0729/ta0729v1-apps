# うみの うちあい — 画像パーツ計画（ナノバナナ）

盤（10×10 のマス）・数字・座標の文字・ヒントの点線わくは、プログラムで描く（画像にしない）。

## 共通の画風
- 男の子向けの かっこいい海の戦い。つやのある 3D ゲーム風（スマホゲームの高品質）、でも小学1〜2年生向けに明るく、こわすぎない。
- このアプリだけのオリジナル。実在の軍艦・既存ゲームに似せない。文字・数字・ロゴを入れない。
- 船・エフェクトは**真上から見た図**、白一色の背景（あとで透明にする）。
- 色：深い海の青・ネイビー・金・赤のアクセント。光は左上から。

## まとめて作るシート（1枚に複数パーツ。間は白い余白を広く、重ねない）
| シート | 中身 | 切り分け後のファイル名 |
|---|---|---|
| S1 船（自分） | 真上から見た船5そうを横向きで縦に並べる：5マス（大きな戦艦）・4マス（空母風）・3マス（巡洋艦）・3マス（潜水艦）・2マス（小さな高速艇）。長さの比は 5:4:3:3:2、太さは同じ | `ship5.png` `ship4.png` `ship3a.png` `ship3b.png` `ship2.png` |
| S2 エフェクト | 命中の爆発（オレンジの炎と煙）、はずれの水しぶき（白い波紋）、沈没の煙と炎、照準マーク（赤い円の十字） | `fx_hit.png` `fx_miss.png` `fx_sink.png` `fx_aim.png` |
| S3 UI | 金ぶちの紺色ボタン（文字なし・横長）、金ぶちの紺色パネル、番の表示のバッジ（青・オレンジの2色） | `ui_button.png` `ui_panel.png` `ui_turn_me.png` `ui_turn_cpu.png` |

## 1枚ずつ作るもの
| ファイル名 | 中身 | 比率 |
|---|---|---|
| `sea_tile.png` | 真上から見た海の水面（波・光の模様）。つなげても継ぎ目が目立たない模様 | 正方形 |
| `bg.jpg` | 画面の背景：夕方〜夜の海、遠くに島と灯台、水平線（文字なし） | 縦長 9:16 |
| `title_art.jpg` | タイトル絵：2つの艦隊が海で向かい合う、照準と水しぶき | 横長 3:2 |
| `icon.png` | アイコン：船と照準マーク、紺の背景 | 正方形 |

## 組み込み方（Claude がする）
- 船・エフェクト・UI は白背景を透明にして余白を切る。船は横向きの画像を、たて置きのときは90度回して使う。
- 船：幅 600px 以下、エフェクト 256px、UI 600px 以下、bg・title_art は 1600px 以下の jpg、icon は 180px と 512px。
- 画像がないパーツは、今の絵（図形）のまま動く。
